# Vendor feature deepsearch: 50+ clean-room feature candidates
This file records a clean-room feature survey for DirtyJTAG. It intentionally captures reusable product concepts, public interface ideas, and workflow patterns. It does **not** copy proprietary protocols, source code, firmware, command byte streams, DLL behavior, or vendor confidential algorithms.
- Entries: **71** vendor/product rows
- Unique vendors: **69**
- Status summary: `{"implemented-partial": 6, "planned": 41, "research": 24}`

## Highest-value implementation themes
1. **Composite probe UX**: CDC serial + SWD/JTAG + protocol bridges + target-power telemetry, inspired by DAPLink, STLINK-V3, MCU-Link Pro, KitProg3 and Raspberry Pi Debug Probe.
2. **Trace-first debugging**: RTT, SWO/ITM, SystemView-style event streams, RTOS/thread awareness, and timing export, inspired by SEGGER, Lauterbach, iSYSTEM, IAR and pyOCD.
3. **Power-aware debugging**: target current measurement and event-correlated energy logs, inspired by Keil ULINKplus, IAR I-jet, TI EnergyTrace, Renesas E2, NXP MCU-Link Pro and PEmicro FX.
4. **Bridge and bootloader modes**: UART/SPI/I2C/CAN/GPIO bridge commands and scripted reset/boot entry flows, inspired by STLINK-V3, KitProg3, ESP-Prog, Total Phase and Bus Pirate.
5. **Production programming**: offline job bundles, serialization, verify policy, logs and multi-probe scheduling, inspired by PICkit 5 Programmer-to-Go, Elnec, BPM, Data I/O, FlashRunner and DediProg.
6. **Board-level test**: BSDL/SVF/boundary-scan chain discovery, net tests and coverage reports, inspired by XJTAG, Corelis, JTAG Technologies, ASSET and GOEPEL.
7. **Pack/descriptor-driven algorithms**: CMSIS-Pack/PDSC, Microchip DFP and JSON profiles rather than hard-coded algorithm guesses.

- Add production job manifest: image, device profile, voltage, erase/write/verify policy, serialization, operator notes, output report.
- Add BSDL/SVF research scaffold for board-level JTAG chain discovery and IDCODE reporting.
